A premium, cyber-themed cryptocurrency market dashboard that monitors real-time trading values, 24-hour fluctuations, and overall market capitalization for the top 20 global digital assets.

## ✨ Key Features
- **Live WebSocket/API Streaming:** Integrated with the highly stable CryptoCompare API to dynamically fetch, map, and render financial data blocks.
- **Instant Client-Side Filtering:** An optimized, high-speed JavaScript input event listener that filters names and asset ticker symbols simultaneously in real-time.
- **Automated Algorithmic Analytics:** Custom JS logic parses the incoming data array upon retrieval to instantly compute and showcase the "Top Gainer of the Day".
- **Cyberpunk UI Theme:** Built with sharp neon accents, glowing pulse status indicators, and clean layout grids tailored for a cinematic developer experience.
- **No-Refresh Auto Update:** Utilizes asynchronous intervals to update data in the background every 60 seconds without breaking user interaction.

## 🛠️ Built With
- **HTML5:** Semantic architecture optimized for clean DOM insertion.
- **CSS3:** Custom neon glow properties, keyframe pulsing animations, and grid layout wrappers.
- **Vanilla JavaScript:** Advanced `async/await` fetch sequences, data mapping methods, and custom analytical filters.
